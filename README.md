# 駐車場自動配置ツール

平面・乗用車を対象に、敷地形状から駐車台数を概算・自動配置する検討用の単一HTMLアプリです。
外部ライブラリに依存せず、`index.html` 単体で動作します。

## 使い方

GitHub Pages で公開されたページをブラウザで開くだけです。
ローカルで動かす場合も `index.html` をブラウザで開くだけで動作します。

## 主な機能

- 敷地・障害物・手動車路の作図／編集（オブジェクトスナップ・直交モード対応）
- DXF 下図の読み込みと 2 点校正、配置方向の自動最適化
- 外周車路／外周車室／緑化帯の設定、駐車台数・原単位・面積の算出
- DXF・PNG 書き出し、検討状態の保存／読込

## 注意

本ツールは計画初期の概算検討用です。条例上乗せ・附置義務・車いす使用者用区画・
車両軌跡検証などは対象外です。
