# 駐車場自動配置ツール（検討用）

平面・乗用車を対象に、敷地形状から駐車台数を概算・自動配置する検討用の単一HTMLアプリです。
外部ライブラリに依存せず、`index.html` 単体で動作します。

## 使い方

GitHub Pages で公開されたページをブラウザで開くだけです。
ローカルで動かす場合も `index.html` をブラウザで開くだけで動作します（サーバー不要、ネットワーク接続不要）。

## 主な機能

- 敷地・障害物・手動車路の作図／編集（頂点ドラッグ・辺への頂点追加・削除、寸法付きラバーバンド表示、自己交差の検出）
- ホイールズーム（カーソル中心）・中ボタンドラッグでのパン、Undo／Redo（`Ctrl+Z` / `Ctrl+Y`）
- DXF 下図の読み込み（ASCII DXF、レイヤー表示切替、2 点校正）となぞり入力
- 配置方向の自動最適化（手動角度でのリアルタイム再配置にも対応）
- 外周車路／外周車室／緑化帯の設定、駐車台数・原単位・面積（車室・車路・障害物・緑地）の算出
- 車路と車室の間の余剰を緑地として集計し、緑地率などの検討指標として表示
- 行き止まり車路・障害物との干渉など、計画品質のチェックと警告表示
- 作業内容の自動保存（`localStorage`）と離脱時の警告
- DXF（画面表示と一致するレイヤー構成）・PNG（図形全体を収めた出力）での書き出し、検討状態の保存／読込

再構築・詳細仕様は [仕様書.md](./仕様書.md) を参照してください。画面構成、入力操作、配置エンジンの計算式、

## 注意

本ツールは計画初期の概算検討用です。条例上乗せ・附置義務・車いす使用者用区画・
車両軌跡検証などは対象外です（詳細は仕様書 §12「対象外の機能」）。
